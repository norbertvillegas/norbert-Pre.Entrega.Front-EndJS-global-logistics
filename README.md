# Norbert Global Logistics

Sitio web corporativo responsive desarrollado como proyecto académico de Front-End para una **empresa logística ficticia**. Norbert Global Logistics no es una empresa real.

## Descripción

Sitio corporativo responsive orientado a presentar servicios logísticos, cobertura operativa, reseñas y un formulario de contacto/cotización.

## Tecnologías

- HTML5 semántico
- CSS3
- Flexbox
- CSS Grid
- Media Queries
- JavaScript vanilla
- Google Fonts — Montserrat
- Formspree
- HTML5 Video

## Funcionalidades

- Navegación interna por secciones
- Hero responsive
- Cards responsive de Servicios con Flexbox
- Sección Cobertura
- Video HTML5 responsive 16:9
- Flujo Origen → Hub logístico → Destino
- Carrusel de reseñas con JavaScript vanilla
- Reseñas organizadas mediante CSS Grid
- Formulario de contacto integrado con Formspree
- Diseño responsive para desktop, tablet y mobile

## Estructura

```
index.html

README.md
```

## Responsive Design

El layout se adapta con Flexbox, CSS Grid y Media Queries. También se utilizan `clamp()`, imágenes y video adaptables, `aspect-ratio` y `object-fit` para mantener proporciones sin romper el diseño.

## Multimedia

La sección Cobertura integra un video local HTML5 en formato MP4 con controles nativos del navegador, imagen `poster` y un contenedor responsive 16:9.

## Formulario

El formulario de contacto utiliza [Formspree](https://formspree.io/) para enviar **nombre**, **email** y **mensaje**. No incluye credenciales ni datos privados en el repositorio.

## Ejecución local

Abrí `index.html` directamente en tu navegador (doble clic o arrastrar el archivo a una ventana).

Durante el desarrollo también podés usar **Live Server** u otra extensión similar para recargar cambios automáticamente.
